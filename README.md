# Голоса палаты

[Открыть опросники](https://mratton3-netizen.github.io/golosa-palaty/) · [Telegram @MUESLIMEDICA](https://t.me/MUESLIMEDICA)

Опросники перед приёмом психиатра для взрослых: HADS, AQ-10, ASRS-5, BIS-brief и HCL-8. 46 вопросов, адаптивный интерфейс для телефона и компьютера.

Сайт работает без регистрации. Ответы, возраст и выбранный пол хранятся только в памяти вкладки. Приложение не отправляет ответы на сервер, не использует cookies и браузерные хранилища. Копирование, печать и открытие почтового приложения запускаются самим пользователем. Перезагрузка очищает прохождение.

## Запуск и настройка

Весь сайт находится в `index.html`: HTML, CSS, JavaScript и встроенная SVG-графика. Для локального запуска достаточно открыть файл в браузере. Внешние библиотеки не используются; шрифты загружаются через Google Fonts.

Адрес врача задаётся константой `DOCTOR_EMAIL` в начале скрипта. Сейчас это предусмотренная заглушка `doctor@example.com`; перед использованием отправки результатов замените её на свой адрес.

Кнопка с паузой уменьшает движение. Настройка системы `prefers-reduced-motion` также учитывается. Параметры переходов собраны в объекте `MOTION`; фон и стеклянная карточка сохраняются при смене вопросов.

## Границы интерпретации

Результаты являются скринингом и не устанавливают диагноз. Пол меняет грамматическую форму; возраст проверяет применимость взрослого набора. Эти данные не используются для выдуманных поправок к баллам.

ASRS-5 показывает простую сумму 0–24 без пороговой оценки: для взвешенной оценки требуется официальный ключ. BIS-brief показывает сумму без категории риска. Не заменяйте эти ограничения произвольными порогами.
